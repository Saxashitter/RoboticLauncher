# RoboticLauncher
An SRB2 launcher aiming to please all kinds of SRB2 players and modders, featuring debug tools and general conveniences you won't get from simply opening SRB2, such as multiple default skins when you join servers.

I'm not at a state in it where I can say this is reliable yet, but it will be great. Just trust me.

This uses LOVE2D 12 to run. It's entirely made in lua, and I made sure it's easy to understand and modify.
